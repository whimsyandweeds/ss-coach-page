# Sophie + Sage — Coach Page

Calm, trauma-informed landing page for Sophie + Sage, a logistics exit concierge for coaches.

## Setup

1. Create an `images/` folder in the repository root.
2. Upload these three images into it (matching the filenames used in `index.html`):
   - `keys-checklist.jpg` (hero flat-lay with keys, checklist, wooden house)
   - `phone-blurry.jpg` (the blurry phone + shredder image)
   - `exit-mapping.jpg` (the Exit Strategy Mapping paper)

Then open `index.html` or enable GitHub Pages on the `main` branch (Settings → Pages → Deploy from branch → main / root).

The questionnaire at the bottom is fully functional on the client side: select chips, submit to see a summary, and copy it.

The blurry phone image is used in the "Built for the monitored" section.
